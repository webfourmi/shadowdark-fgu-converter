Utilisation dans Fantasy Grounds

Procédure joueur : transfere ton fichier.xml à ton MJ pProcédure MJ uniquement Place ensuite ce fichier dans le dossier : 

Fantasy Grounds / characters

Puis ouvre Fantasy Grounds Unity /characters et utilise la fenêtre d’import de personnage ( la 1ere en bas a droite apres barre recherche).appuyer un 2eme fois pour ouvrir le dossier et cliquer sur le fichier du pj, puis ouvrir.ensuite la fleche (return character selection) Dans la fenêtre d’import, l’aperçu peut afficher « Name », mais après clic sur le bouton +, le personnage est correctement ajouté avec son vrai nom. y a plus qu a cliquer sur le pj.
