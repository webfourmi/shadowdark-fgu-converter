
# Shadowdark FGU Converter

Convertisseur JSON Shadowdark vers XML compatible avec mon ruleset Fantasy Grounds Unity.

## Version actuelle

Importe actuellement :

- Nom
- Ascendance
- Classe
- Niveau
- Caractéristiques
- PV
- CA
- Pièces
- Inventaire
- Langues
- Talents
- Sorts
- maj pour recuperer et traduire les classes des scrolls

## Utilisation

1. Coller le JSON du générateur.
2. Cliquer sur Convertir.
3. Télécharger le XML.
4. Importer le personnage dans Fantasy Grounds Unity.
